# Data Dictionary

## PostgreSQL

| Table | Column | Type | Meaning and constraints |
| --- | --- | --- | --- |
| `users` | `id` | `BIGINT` | Primary key generated by PostgreSQL. |
| `users` | `full_name` | `VARCHAR(120)` | Required display name, at least two non-space characters. |
| `users` | `email` | `VARCHAR(320)` | Required email-like value, unique case-insensitively. |
| `users` | `role` | `VARCHAR(20)` | `Student` or `Admin`; server authorization is a later phase. |
| `users` | `password_hash` | `TEXT` | Reserved for a future password hash, never plaintext. |
| `items` | `seller_id` | `BIGINT` | Required foreign key to `users.id`. |
| `items` | `category` | `VARCHAR(60)` | Required marketplace category. |
| `items` | `price` | `NUMERIC(12,2)` | Required positive monetary amount. |
| `items` | `status` | `VARCHAR(20)` | `Available`, `Reserved`, `Sold`, or `Removed`. |
| `orders` | `buyer_id` | `BIGINT` | Required foreign key to `users.id`. |
| `orders` | `status` | `VARCHAR(20)` | Pending, Confirmed, Completed, Cancelled, or Failed. |
| `orders` | `total_amount` | `NUMERIC(12,2)` | Required non-negative order total. |
| `order_items` | `order_id` | `BIGINT` | Required foreign key to `orders.id`. |
| `order_items` | `item_id` | `BIGINT` | Required foreign key to `items.id`, unique across sales. |
| `order_items` | `unit_price` | `NUMERIC(12,2)` | Required positive price captured at order time. |
| `payment_logs` | `order_id` | `BIGINT` | Required foreign key to `orders.id`. |
| `payment_logs` | `provider` / `provider_reference` | `VARCHAR` | Simulated provider and optional idempotency reference. |
| `payment_logs` | `status` | `VARCHAR(20)` | Pending, Succeeded, Failed, or Refunded. |
| `payment_logs` | `amount` | `NUMERIC(12,2)` | Non-negative simulated payment amount. |

All five business tables also have `created_at`; `users`, `items`, and `orders` have `updated_at`.

## MongoDB

| Collection | Field | BSON type | Meaning and constraints |
| --- | --- | --- | --- |
| `listings` | `postgresItemId` | `long` | Required unique reference to PostgreSQL `items.id`. |
| `listings` | `title`, `description` | `string` | Required searchable metadata with length limits. |
| `listings` | `category`, `condition`, `status` | `string` | Flexible listing metadata constrained to documented values. |
| `listings` | `attributes` | `object` | Category-specific flexible fields. |
| `listings` | `imageMetadata` | `array` | Bounded image metadata; binary files are not stored here. |
| `reviews` | `postgresItemId` | `long` | Required listing reference. |
| `reviews` | `reviewerId` | `long` | Required PostgreSQL user reference. |
| `reviews` | `rating` | `int` | Required integer from 1 through 5. |
| `reviews` | `reviewText` | `string` | Required bounded review text. |
| `reviews` | `createdAt` | `date` | Required review timestamp. |
